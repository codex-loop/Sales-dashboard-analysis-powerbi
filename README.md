# Sales-dashboard-analysis-powerbi
Built an interactive Sales Dashboard using Microsoft Power BI to analyze sales, profit, regions, and product performance using dynamic visualizations and KPI metrics.
## Project Overview

This project is an interactive Sales Dashboard built using Power BI to analyze sales performance, profit trends, customer segments, and regional business insights.

The dashboard helps identify:
- Top-performing regions
- High-profit product categories
- Sales trends over time
- Top-selling products
---

## Tools & Technologies Used

- Power BI
- Power Query
- DAX
- Excel / CSV Dataset

## Dashboard Features

### KPI Cards
- Total Sales
- Total Profit
- Total Quantity
- Profit Value

### Visualizations
- Sales by City
- Profit by Region
- Yearly Sales Trend
- Top Products
- Sales by Region
- Profit by City
- Category Profit Analysis
- Profit by Segment

### Interactive Features
- Filters and slicers
- Dynamic visual updates
- Business insight analysis

---

## Key Business Insights

- West region generated the highest sales and profit.
- Technology category contributed maximum profit.
- Some cities showed low profitability despite high sales.
- Sales increased significantly during later years.
